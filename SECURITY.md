# Security Policy

ProTechnology Limited takes the security of its software, systems and users seriously. We appreciate responsible security researchers and developers who help us identify and address vulnerabilities.

## Supported Projects

This policy applies to software repositories maintained under the ProTechnology Limited GitHub organization:

https://github.com/ProTechnology-Limited

Individual repositories may publish additional security policies or supported-version information. Where these exist, follow the project-specific policy.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, pull requests or social media.

Send a private report to:

Email: protech.limited.co@gmail.com

Suggested subject: Confidential Security Report — [Project Name]

Include the following information:

- The affected project and repository.
- The affected version or commit, if known.
- A description of the suspected vulnerability.
- The potential security impact.
- Steps to reproduce the issue safely.
- Suggested mitigation, if available.
- Your contact details.

Do not include passwords, private keys, access tokens, customer information or other sensitive data in public reports.

## Responsible Disclosure

We ask security researchers to:

- Test only systems and accounts they own or have permission to test.
- Avoid accessing, modifying or disclosing other people's data.
- Avoid denial-of-service attacks and activities that disrupt services.
- Avoid phishing, social engineering and physical attacks.
- Keep vulnerability details confidential while the issue is being investigated.
- Allow ProTechnology Limited a reasonable opportunity to investigate and address reported vulnerabilities before public disclosure.

## Scope

This policy covers security vulnerabilities in software and services maintained by ProTechnology Limited.

Third-party services, dependencies and infrastructure operated by other organizations may have separate security reporting procedures.

Do not conduct unauthorized testing against production systems.

## Response and Remediation

ProTechnology Limited will assess reports in good faith and may request additional information.

We cannot guarantee a particular response or remediation timeframe.

Where appropriate, we may acknowledge a valid report and credit the researcher with their permission.

## Public Disclosure

Please coordinate public disclosure with ProTechnology Limited.

Do not publish sensitive vulnerability details while a report is under investigation.

## Thank You

Responsible security research helps us build safer software for our customers, users and development community.
