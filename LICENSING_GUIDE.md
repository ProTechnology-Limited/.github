# ProTechnology Limited — GitHub Licensing Guide

## Purpose

This document establishes the licensing approach for software, applications, developer tools, and other intellectual property published under the ProTechnology Limited GitHub organization.

## 1. Proprietary Projects

Projects developed as commercial products or owned business platforms may remain proprietary.

Unless a repository contains an explicit open-source licence, no permission is granted to copy, distribute, modify, sublicense, or commercially exploit its source code.

This approach is recommended for:
- ProTrader
- Nexus AI
- ProTechnology Limited's official website
- Other commercial applications and platforms

## 2. Open-Source Projects

Projects intentionally released for public use may adopt an appropriate open-source licence.

Approved options include:

- MIT License: permissive reuse with attribution and preservation of the licence notice.
- Apache License 2.0: permissive reuse with additional provisions, including express patent licensing terms.

Each open-source repository must contain its own LICENSE file.

## 3. Third-Party Dependencies

All projects must respect the licences of third-party libraries, frameworks, APIs, fonts, images, and other dependencies.

Developers must review dependency licences before including third-party materials in commercial products.

## 4. Contributions

Contributors must only submit work they have the legal right to contribute.

Each repository should include contribution guidelines explaining how contributions are reviewed and accepted.

## 5. Intellectual Property

ProTechnology Limited retains ownership of its original proprietary software, source code, branding, documentation, and other intellectual property, subject to applicable agreements and third-party rights.

## 6. Repository Requirements

Every repository should clearly state:

- Project ownership
- Whether the project is open-source or proprietary
- Applicable licence
- Contribution requirements
- Third-party dependency acknowledgements
- Security reporting instructions

## 7. Review

Licensing decisions should be reviewed before a project is released publicly or made available for commercial distribution.
