## About ProTrader

ProTrader is an ambitious financial technology project developed to explore the future of accessible multi-market trading.

The platform brings together trading tools, digital asset discovery, token launch opportunities, staking concepts, trading automation and wallet connectivity in a unified interface.

The project is being developed with a focus on usability, accessibility, performance, security and future scalability.

Our long-term objective is to develop ProTrader into a comprehensive financial technology ecosystem.

## Core Features

### 1. Multi-Market Trading

Explore multiple financial markets through one platform.

Supported market categories include:

- Cryptocurrency markets.
- Commodity markets.
- Stock markets.
- Emerging digital assets.

### 2. Memecoin Launchpad

A proposed ecosystem for discovering and exploring new token launches and memecoin projects.

### 3. Tokenized IPO Listings

An initiative exploring tokenized investment opportunities and digital representations of investment offerings.

Actual availability will depend on implementation, applicable regulations and supported integrations.

### 4. Airdrop Discovery

Explore vetted airdrop opportunities and discover emerging blockchain projects.

### 5. Staking

A staking feature designed to support future digital asset participation.

### 6. Launchpool

An ecosystem for exploring token launch participation and related opportunities.

### 7. Trading Bots

A developing feature for automated trading strategies and trading assistance.

### 8. Wallet Connectivity

Wallet connection functionality designed to support compatible cryptocurrency wallets.

Current wallet integration targets include:

- MetaMask.
- Phantom.

Wallet functionality depends on the installed wallet, supported network and implementation status.

### 9. Deposits and Account Interface

The application includes interfaces for account balances and deposits as part of its broader financial technology design.

Important: Current prototype balances and deposit interactions are simulated. No real funds are transferred or deposited.

## Current Development Status

ProTrader is currently a front-end prototype operating in demo mode.

The following functionality is simulated in the browser using localStorage:

- Market prices.
- Account balances.
- Deposits.
- Token launches.
- Trading bot activity.
- Selected trading interactions.

These simulated features allow developers and testers to explore the interface and evaluate the user experience.

The prototype does not currently execute real trades, process real deposits or move real money.

Features are subject to ongoing development, testing and upgrades.

## Installation and Local Development

### Requirements

- A computer running Windows, macOS or Linux.
- Visual Studio Code or another code editor.
- A modern web browser.
- Internet connection for Google Fonts and external resources.

### Option 1: Run with VS Code

1. Download or clone the repository.
2. Extract the project if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Install the Live Server extension.
5. Open index.html using Live Server.

### Option 2: Run with Node.js

If the project has the required package configuration:

bash npm install npm start 

Alternatively, use:

bash npx serve . 

### Option 3: Open Directly

You can also open index.html directly in a modern browser.

Some external integrations may require a local server or additional configuration.

## Configuration

The application includes a configuration file:

text js/config.js 

This file manages settings such as:

- Application branding.
- Interface colours.
- Fees.
- Launch rules.
- Feature flags.

The project also uses:

text js/store.js 

This manages application state and local browser persistence.

Do not place sensitive credentials, private keys, API secrets or production access tokens in public JavaScript files.

Future production integrations should use secure backend services and server-side environment variables.
